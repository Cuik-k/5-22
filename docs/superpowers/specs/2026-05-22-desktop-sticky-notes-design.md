# Desktop Sticky Notes — 设计规格说明书

## 概述

一款 Windows 桌面便签软件，支持富文本编辑、待办清单、外观高度自定义、每张便签独立窗口自由摆放。纯本地存储，自动保存，启动恢复。Electron + React + TypeScript 技术栈。

---

## 技术选型

| 层 | 选择 |
|---|---|
| 框架 | Electron + React + TypeScript |
| 富文本编辑器 | TipTap（ProseMirror 底层） |
| 数据存储 | better-sqlite3 |
| 构建工具 | Vite + electron-vite |
| 样式 | Tailwind CSS |
| 默认托盘图标 | 简约线条图标（便签/图钉图案），SVG 转 .ico |

### 选 TipTap 而不选其他的原因
- Quill：DOM 模型封闭，悬停拖拽自定义受限
- Slate.js：灵活但不稳定，API 频繁变动
- TipTap：ProseMirror 底层 + React 封装，文档齐全，插件生态好，便于实现悬停高亮和拖拽移动文字

## 架构

```
┌─────────────────────────────────────────────┐
│              Electron Main Process          │
│                                             │
│  ┌──────────┐  ┌──────────┐  ┌───────────┐ │
│  │ 窗口管理  │  │ 系统托盘  │  │ 全局快捷键 │ │
│  └──────────┘  └──────────┘  └───────────┘ │
│                     │                       │
│              ┌──────┴──────┐                │
│              │  SQLite 持久层 │              │
│              └──────────────┘               │
│                     │                       │
│              ═══ IPC 通道 ═══               │
│                     │                       │
│  ┌──────────────────┼───────────────────┐  │
│  │        Renderer (React + TS)         │  │
│  │                                      │  │
│  │  控制面板界面  │  便签窗口  │  设置页  │  │
│  └──────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

- 主进程负责窗口生命周期、托盘、全局快捷键、SQLite 数据读写
- 渲染进程通过 IPC 与主进程通信（查询、创建、更新、删除便签）
- 每张便签是独立 BrowserWindow，无边框，渲染各自的 React 组件
- 控制面板和设置页各自也是一个 BrowserWindow

## 数据模型

SQLite 单表 `notes`：

```sql
CREATE TABLE notes (
  id            TEXT PRIMARY KEY,           -- UUID
  title         TEXT DEFAULT '',            -- 便签标题
  content       TEXT DEFAULT '',            -- 富文本 HTML
  color         TEXT DEFAULT '#FFE066',     -- 背景色
  font_size     TEXT DEFAULT '14px',       -- 字体大小
  opacity       REAL DEFAULT 0.92,         -- 不透明度
  border_radius TEXT DEFAULT '8px',        -- 圆角
  shadow        TEXT DEFAULT 'medium',     -- 阴影强度
  x             REAL DEFAULT 100,          -- 窗口 X
  y             REAL DEFAULT 100,          -- 窗口 Y
  width         REAL DEFAULT 280,          -- 窗口宽度
  height        REAL DEFAULT 320,          -- 窗口高度
  pinned        INTEGER DEFAULT 0,         -- 是否置顶
  is_checklist  INTEGER DEFAULT 0,         -- 清单模式
  created_at    TEXT DEFAULT (datetime('now')),
  updated_at    TEXT DEFAULT (datetime('now'))
);
```

- 内容存 HTML，TipTap 原生输出格式，直接读写
- 窗口位置/大小/外观完整持久化，启动精确复原
- 每张便签独立记录所有参数，互不影响

## 便签窗口

### 布局

```
┌─────────────────────────────────────┐
│  ≡ 拖拽      [标题栏]         📌     │  ← 顶部工具栏
│                                     │
│  ┌───────────────────────────────┐  │
│  │                               │  │
│  │     富文本编辑区 (TipTap)      │  │
│  │    悬停高亮文字               │  │
│  │    可拖拽移动高亮文字          │  │
│  │                               │  │
│  └───────────────────────────────┘  │
│                                     │
│  🎨 外观   ✓清单   ⊕复选框   🗑删除  │  ← 底部工具栏
└─────────────────────────────────────┘
```

### 交互

| 区域 | 行为 |
|---|---|
| 顶部栏 | 拖拽移动窗口（`-webkit-app-region: drag`） |
| 标题栏 | 双击编辑标题，Enter 确认 |
| 📌 按钮 | 切换置顶/取消 |
| 编辑区 | 富文本：加粗/斜体/下划线/列表/文字颜色/背景色 |
| 鼠标悬停文字 | 当前词高亮显示，按住拖拽到编辑区新位置释放 |
| 🎨 按钮 | 弹出外观面板：背景色、透明度、字号、圆角、阴影 |
| ✓ 按钮 | 切换清单模式（每行前加 checkbox，已完成划掉变灰） |
| ⊕ 按钮 | 在光标位置插入复选框 |
| 🗑 按钮 | 删除便签（二次确认） |
| 右下角 | 拖拽缩放窗口 |
| 双击标题栏空白 | 折叠/展开（仅显示标题栏） |
| 右键标题栏 | 上下文菜单：置顶、外观、复制内容、导出 txt、删除 |

### 悬停高亮 + 拖拽文字

- 监听鼠标移动，通过 `document.caretRangeFromPoint()` 定位光标下文字节点
- 给匹配的文本片段加高亮样式（背景色发光效果）
- 拖拽生命周期：mousedown → mousemove（拖动影子） → mouseup（计算插入位置并移动文本）
- 绕开浏览器原生文本选择和拖拽行为，对 TipTap 内部文档模型做精确操作

| 快捷键 | 功能 |

## 保存策略

- 编辑时 **500ms 防抖自动保存** 到 SQLite
- 窗口移动/缩放结束时保存位置和尺寸
- 关闭窗口时立即保存
- 启动时从 SQLite 读取全部便签，按记录位置/大小重建窗口
